# latex — paper drafts (Overleaf-compatible)

LaTeX sources for manuscripts and write-ups. This folder may hold **multiple
independent projects** — give each its own subfolder with its own `main.tex`:

```
latex/
├── README.md
├── healthbench-grounding/        # e.g. the main paper
│   ├── main.tex
│   ├── references.bib
│   └── sections/
└── workshop-abstract/            # e.g. a short submission (separate project)
    └── main.tex
```

> No `.tex` files are committed yet — we're still at the idea / literature-review stage.
> Create a subfolder when a write-up actually starts.

## Overleaf ⇄ GitHub workflow

Overleaf syncs against a **whole GitHub repository**, so this `latex/` folder rides along
with the rest of Auto-Health-Bench. Two common setups:

**A. One Overleaf project ↔ this repo (recommended for a single paper).**
1. In Overleaf: **New Project → Import from GitHub** → select `yfan2676/Auto-Health-Bench`.
   (Requires linking your GitHub account under Overleaf *Account Settings → GitHub*.)
2. Open **Menu → Settings → Main document** and set it to your paper's entry file,
   e.g. `latex/healthbench-grounding/main.tex`.
3. Edit in Overleaf, then **Menu → GitHub → Push/Pull** to sync commits both ways.

**B. A standalone Overleaf project per paper.** Keep the Overleaf project separate and
periodically copy the sources into the matching `latex/<project>/` subfolder here (or use
Overleaf's git remote to pull). Use this if you want the paper's history decoupled from
the experiment log.

## Conventions

- One subfolder per paper/manuscript; `main.tex` is the entry point in each.
- Keep `references.bib` next to the `main.tex` that uses it.
- Build artifacts (`*.aux`, `*.bbl`, `*.out`, `*.synctex.gz`, …) are git-ignored — commit
  **sources only**. Overleaf compiles from source.
- Figures/tables generated by an experiment belong with that experiment under
  `experiments/*/results/`; copy only the final figure into the paper subfolder.
