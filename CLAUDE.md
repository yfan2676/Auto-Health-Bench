# Project guidance for Claude Code

## Writing style

- **Do not use em-dashes (—) in prose.** Rephrase instead, using commas, colons,
  parentheses, semicolons, or separate sentences, whichever reads most naturally for the
  sentence. This applies to all docs and any new prose written for this project. (En-dashes
  in numeric ranges, e.g. "Phase 1–3", are fine.)
- Prefer plain, simple, clear language. Do not add self-referential statements that
  describe a document's own nature to the reader (e.g. "this is a plain-language overview",
  "this readable summary"). Such characterizations belong in the index/README entry for the
  doc, not inside the doc itself.
