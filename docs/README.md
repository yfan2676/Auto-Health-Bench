# docs — ideas & literature

High-level, slow-changing material: the project vision and the running literature
review. The fast-moving execution work lives under [`../experiments/`](../experiments/).

## Contents

| File | What it is |
|---|---|
| [`vision.md`](vision.md) | **The full project idea** — motivation, research questions, the data-conditioned evaluation method, study directions (N1–N4), opportunities, risks, datasets, pipeline, phase plan, and resolved decisions. Start here. |
| [`lit-review/`](lit-review/) | Running literature-review index, organized by the themes the project touches. |
| `Data-Grounded-Health-AI-Overview.docx` | Plain-language overview for non-technical stakeholders. Generated by `experiments/data-grounded-healthbench/src/docx/make_overview.py`; contains only high-level prose + aggregate numbers (safe to share). |

## How this relates to the experiments

`vision.md` defines *what good looks like* and *why*; each experiment under
`experiments/` implements and tests a slice of it, and writes its findings back into the
vision's framing. When an experiment changes the picture (a new number, a refuted
assumption), update `vision.md` so it stays the canonical statement of the idea.
